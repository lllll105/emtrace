# Key Findings — Oracle Event / Full Oracle

- Across Emotion Label, Multilayer Vector, and NPTI, correcting emotion produces the larger average gain in emotion accuracy.
- Correcting the event produces the more consistent gain in original-text entailment, so affect realization and event grounding have distinct bottlenecks.
- Full Oracle improves emotion accuracy over Normal by +3.75, +7.38, and +3.77 percentage points for Emotion Label, Multilayer Vector, and NPTI.
- Accuracy interactions are generally small; most method-level bootstrap intervals include zero, with limited method-specific interaction in Multilayer Vector.
- Exact McNemar tests use one Holm family of 77 unique hypotheses; 32 remain significant at 0.05.
- Full Oracle is generated once per family and is not counted five times as independent evidence.
